    How to score

    1. Set up

    On Setup, enter the sheet heading, both teams and their players' shirt numbers. Tick St for each team's starting five.

    2. Score

    On Live, tap a team's score at the top to pick that team, then use the player's buttons:

    • +1 a made free throw, +2 / +3 a field goal
    • F a foul: choose the type and the free throws awarded

    Time-outs and coach or bench fouls are under the player cards.

    3. Fix mistakes

    Undo removes the last entry. Log lists every entry: tap ✕ to delete one, then Undo in the message if that was a slip.

    If something breaks a rule, the app asks first. You can always record it anyway: the sheet records what actually happened.

    4. Periods and the end

    Tap End Q1 (and so on) when each period ends, and End game at the final buzzer.

    5. Export

    On Sheet, export the PDF. Save JSON keeps a copy of the game you can import on any phone.

    Your games stay on this phone

    Nothing is uploaded. Clearing the browser's data deletes saved games, so export anything you need to keep.

    Install it so it opens like an app and works with no signal:

    • iPhone (Safari): Share → Add to Home Screen
